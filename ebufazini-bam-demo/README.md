# Ebufazini Bam Online Store Demo

Client demo for the proposed Ebufazini Bam online boutique.

## Demo features
- Product catalogue
- Shopping cart
- Delivery details form
- Online payment flow mockup
- Order management dashboard
- Unattended-order reminder example

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deployment
This demo can be deployed with GitHub Pages, Vercel, or Netlify.
